Barangay Nazareth Integrated Waste Management & Barangay Management System (Aksyon Basura)

An integrated, full-stack municipal management platform built specifically for Barangay Nazareth, Cagayan de Oro City. 
The system digitizes local government operations with a heavy focus on transparent waste management reporting, real-time 
GPS collection tracking, geospatial mapping via PostGIS, citizen services, blotter records, and document requests.
